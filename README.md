# Ishma-iel Gray Portfolio

This portfolio is now a Vue 3 single-page app built with Vite. The original HTML files remain in the project root as source copies; Vue page components live in `src/pages` and shared navigation lives in `src/components/SiteHeader.vue`.

## Start the development server

Install Node.js 24.12 or newer and npm. In this folder, run:

   ```sh
   npm install
   npm run dev
   ```

Vite will print a local URL to open in your browser. Run `npm run build` to create a production build.
